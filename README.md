# Wangwon Portfolio

> ระบบสร้างแฟ้มสะสมผลงานนักเรียนแบบอัตโนมัติ สำหรับคุณครูโรงเรียนบ้านวังวน

---

## 🎯 วัตถุประสงค์ของโครงการ (Project Overview)

**Wangwon Portfolio** เป็นเว็บแอปพลิเคชันที่ทำงานบนเว็บเบราว์เซอร์โดยตรง (Client-side Web Application) ออกแบบมาโดยเฉพาะสำหรับคุณครูโรงเรียนบ้านวังวน เพื่อช่วยจัดทำแฟ้มสะสมผลงาน (Portfolio) ของนักเรียนเป็นเอกสาร PDF มาตรฐานขนาด A4 ได้อย่างสะดวกรวดเร็ว สวยงาม และเป็นระเบียบเรียบร้อย โดยไม่ต้องพึ่งพาโปรแกรมตกแต่งภาพที่ซับซ้อน

### ลำดับขั้นตอนการทำงานหลัก (Core Workflow)

1. **ข้อมูลนักเรียน (Student Information)**: กรอกข้อมูลพื้นฐาน ได้แก่ คำนำหน้าชื่อ, ชื่อ, นามสกุล, ระดับชั้น (อนุบาล 1 ถึง ประถมศึกษาปีที่ 6), เลขที่, ปีการศึกษา และรูปถ่ายนักเรียน (ตัวเลือกเสริม)
2. **เพิ่มรูปภาพและจัดหน้า (Workspace & Image Arrangement)**: นำเข้ารูปภาพผลงาน/กิจกรรมของนักเรียน จัดลำดับ หมุนภาพ ปรับแต่งหน้าเอกสาร โดยมีปกหน้าอยู่ที่หน้า 1 และปกหลังอยู่ที่หน้าสุดท้ายเสมอ
3. **ตั้งค่าและสร้างไฟล์ (Settings & Export)**: เลือกทิศทางกระดาษ (แนวตั้ง/แนวนอน), การจัดวางภาพ (Fit / Fill), คุณภาพความละเอียด, ลายน้ำโรงเรียน จากนั้นสร้างไฟล์เอกสาร PDF หรือส่งออกเป็นชุดแพ็กเกจ (PDF + รูปภาพ) พร้อมดาวน์โหลดทันที

## ✨ คุณสมบัติเด่นของระบบ (Features)

- **ข้อมูลและรูปนักเรียน**: ฟอร์มกรอกข้อมูลพร้อมการตรวจสอบความถูกต้องแบบ Inline Validation แสดงผลตัวอย่างชื่อไฟล์สด (Live Filename) และรองรับรูปถ่ายนักเรียน (อัตราส่วน 4:5 พร้อมกรอบพรีวิว)
- **รองรับรูปแบบไฟล์ภาพหลากหลาย**: รองรับไฟล์ JPG, PNG (โปร่งใส), WebP, BMP (แปลงเป็น JPEG อัตโนมัติ) และ HEIC/HEIF พร้อมระบบถอดรหัสในตัว
- **เพิ่มรูปหลายภาพพร้อมกัน**: รองรับการเลือกไฟล์ทีละหลายภาพ (Multi-select), การลากและวาง (Drag & Drop) และการวางจากคลิปบอร์ด (Clipboard Paste)
- **ระบบตรวจจับภาพซ้ำ (Duplicate Detection)**: วิเคราะห์ภาพซ้ำอัตโนมัติ พร้อมกล่องข้อความยืนยันให้เลือกว่าจะข้ามหรือนำเข้ารูปซ้ำ
- **ระบบแจ้งเตือนความละเอียดต่ำ (Low-resolution Warning)**: แสดงป้ายเตือนสำหรับรูปภาพที่มีความละเอียดต่ำกว่า 1,200 พิกเซล เพื่อให้คุณครูทราบล่วงหน้าก่อนพิมพ์
- **การจัดการภาพกิจกรรมครบวงจร**: จัดลำดับภาพ (Reorder / Move Earlier / Move Later), หมุนภาพครั้งละ 90 องศา, แทนที่รูปภาพเดิม (Replace), ทำสำเนารูปภาพ (Duplicate), ลบรูปภาพเดี่ยว พร้อมหน้าต่างดูรูปขยายใหญ่ (Lightbox Preview)
- **เทมเพลตหน้าปก 3 รูปแบบ (Cover Templates)**:
  - *โรงเรียนเรียบง่าย (Minimal School)*: ทางการ เรียบหรู เหมาะกับแฟ้มวิชาการ
  - *วิชาการร่วมสมัย (Modern Academic)*: โครงสร้างกริดทันสมัย เหมาะกับการประเมินผลงาน
  - *ผลงานสดใส (Colorful Portfolio)*: โทนสีสร้างสรรค์ สดใส เหมาะกับกิจกรรมเด็ก
- **รองรับการอัปโหลดปกเอง (Custom Front / Back Cover)**: สามารถอัปโหลดไฟล์ภาพปกหน้าและปกหลังที่ออกแบบเองได้ พร้อมปุ่มสลับกลับมาใช้ปกอัตโนมัติ
- **ระบบลายน้ำ (Watermark System)**: เลือกใส่ตราสัญลักษณ์โรงเรียนบ้านวังวน หรืออัปโหลดภาพลายน้ำเอง ปรับความโปร่งใส (Opacity), ขนาด (Scale), ตำแหน่งทั้ง 9 ทิศทาง และเลือกเป้าหมายการประทับลายน้ำได้
- **โหมดสว่าง / โหมดมืด (Light / Dark Mode)**: โทนสี Wangwon Soft Workspace ถนอมสายตา บันทึกสถานะธีมลงใน localStorage ปราศจากอาการจอกะพริบ (Zero-FOUC)
- **การส่งออกเอกสาร PDF (PDF Export)**: ประมวลผลสร้างไฟล์ PDF มาตรฐาน A4 คมชัดระดับสิ่งพิมพ์ พร้อมตั้งชื่อไฟล์ภาษาไทยตามชื่อนักเรียน เช่น `ด.ช.สมชาย_ใจดี.pdf`
- **การส่งออกชุดแพ็กเกจ (PDF + รูปภาพ Export)**: บีบอัดเป็นไฟล์ ZIP บรรจุทั้งไฟล์ PDF และภาพกิจกรรมที่เปลี่ยนชื่อเรียงลำดับเป็น `[ชื่อนักเรียน]_01.jpg`, `[ชื่อนักเรียน]_02.jpg` พร้อมโครงสร้างโฟลเดอร์สะอาด ป้องกัน Path Traversal
- **ระบบบันทึกร่างอัตโนมัติ (Auto Save Draft)**: บันทึกความคืบหน้าของงานลงในเบราว์เซอร์อัตโนมัติแบบ Debounced เพื่อป้องกันงานสูญหาย
- **ระบบกู้คืนงาน (Draft Recovery)**: ตรวจพบงานค้างเมื่อเปิดหน้าเว็บใหม่ พร้อมหน้าต่างสรุปข้อมูลและปุ่มให้เลือกระหว่าง "ทำงานต่อ" หรือ "เริ่มทำแฟ้มใหม่"

## 🛡️ นโยบายและสถาปัตยกรรมความเป็นส่วนตัว (Local-First Privacy Architecture)

Wangwon Portfolio ให้ความสำคัญสูงสุดกับความปลอดภัยของข้อมูลส่วนบุคคลและรูปถ่ายของนักเรียน โดยยึดหลักปฏิบัติด้านความปลอดภัยที่ตรวจสอบได้จริง:

1. **ประมวลผลรูปในเครื่องทั้งหมด (100% In-Browser Execution)**:
   - รูปถ่ายนักเรียน ภาพผลงานกิจกรรม และข้อมูลประวัติทั้งหมด ถูกประมวลผล ถอดรหัส และจัดหน้าภายในหน่วยความจำของเว็บเบราว์เซอร์บนเครื่องคอมพิวเตอร์ของคุณครูเท่านั้น
   - ไม่มีการอัปโหลดรูปภาพหรือส่งข้อมูลนักเรียนไปยังเซิร์ฟเวอร์ภายนอก ระบบคลาวด์ หรือบริการ AI ใดๆ
2. **การจัดเก็บข้อมูลร่างในเครื่อง (IndexedDB Storage)**:
   - ร่างเอกสารที่บันทึกอัตโนมัติจะถูกเก็บไว้ในพื้นที่จัดเก็บฐานข้อมูลภายในเครื่อง (Browser IndexedDB: `wangwon-portfolio-db`) ของเบราว์เซอร์นั้นๆ ไม่มีการส่งออกนอกเครื่อง
   - *หมายเหตุ*: ข้อมูลไม่ได้ถูกเข้ารหัสลับ (No encryption claimed) แต่ถูกแยกพื้นที่จัดเก็บตามมาตรฐานความปลอดภัย Same-Origin Policy ของเบราว์เซอร์
3. **การจัดเก็บการตั้งค่า (localStorage)**:
   - จัดเก็บเฉพาะค่าความชอบส่วนตัว เช่น โหมดธีม (Light/Dark Mode) ลงใน `localStorage` ของเบราว์เซอร์เท่านั้น
4. **ความปลอดภัยต่อไฟล์ต้นฉบับ**:
   - ระบบอ่านข้อมูลแบบ Read-only ไม่มีการเขียนทับ แก้ไข หรือลบไฟล์ภาพต้นฉบับในเครื่องของคุณครู

## 💻 การติดตั้งและเริ่มใช้งาน (Installation & Development)

### ข้อกำหนดเบื้องต้น (Prerequisites)
- [Node.js](https://nodejs.org/) (เวอร์ชัน 18.0.0 หรือใหม่กว่า)

### การติดตั้ง (Setup)
```bash
# ติดตั้ง dependencies สำหรับการพัฒนาและทดสอบ
npm install
```

### การเริ่มรันระบบในเครื่อง (Start Local Server)
```bash
npm start
```
เปิดเบราว์เซอร์ไปที่: `http://localhost:3000`

### การทดสอบระบบอัตโนมัติ (Automated Testing)
```bash
# รันชุดการทดสอบ Playwright ครบทั้ง Desktop Chromium และ Mobile Chrome
node ./node_modules/@playwright/test/cli.js test

# รันการทดสอบพร้อมเปิดหน้าต่าง UI
npm run test:ui
```

## ⚠️ ข้อจำกัดที่ควรทราบ (Known Limitations)

1. **ขีดจำกัดหน่วยความจำของเบราว์เซอร์ (Browser Memory)**: เนื่องจากระบบประมวลผลรูปภาพและสร้างไฟล์ PDF ขนาดเต็มความละเอียดภายในเบราว์เซอร์ หากนำเข้ารูปภาพขนาดใหญ่ (>15–20 MB ต่อรูป) จำนวนมากเกินกว่า 50–100 รูปพร้อมกัน อาจทำให้เบราว์เซอร์บนอุปกรณ์ที่มีแรมน้อยทำงานช้าลง
2. **การทำงานของไฟล์ HEIC/HEIF**: การแปลงไฟล์ภาพตระกูล HEIC/HEIF จากอุปกรณ์ iOS ขึ้นอยู่กับความสามารถของเบราว์เซอร์ หรือไลบรารีถอดรหัสในเครื่อง แนะนำให้ใช้ภาพ JPG หรือ PNG เพื่อประสิทธิภาพสูงสุด
3. **การเข้าถึงงานร่างต่างอุปกรณ์**: ข้อมูลบันทึกร่างอัตโนมัติถูกจัดเก็บในฐานข้อมูลเบราว์เซอร์เฉพาะเครื่องนั้นๆ หากคุณครูเปลี่ยนไปใช้งานบนเครื่องคอมพิวเตอร์อื่น หรือเปิดในเบราว์เซอร์อื่น จะไม่พบงานร่างเดิม
